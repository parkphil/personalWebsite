# Philip Park portfolio

The former site is preserved on `codex/previous-website`. This portfolio is the live replacement.

Project cards and their order are in `content.js`. Case studies are standalone HTML pages. The Craft page is in `craft.html`. Media files live in `public/media/` and are served from `/media/`; images live in `public/images/`.

Run `npm ci` and `npm run dev` to preview, or `npm run build` to create the Vercel output in `dist/`.
